# GeoSolver CAD - Release Notes v3.1.0

## Tiếng Việt (VN)
**Có gì mới trong phiên bản 3.1.0**
- **Cải thiện độ chính xác dựng hình:** Tối ưu hóa thuật toán nhận diện và phân loại tam giác, đảm bảo kết quả nhất quán và chính xác bất kể thứ tự chọn đỉnh.
- **Tương tác trực quan mượt mà hơn:** Cải tiến cơ chế kéo thả các điểm tự do, trung điểm và các đối tượng hình học phụ thuộc; toàn bộ hình vẽ luôn được cập nhật đồng bộ và tự nhiên.
- **Hoàn tác & Làm lại (Undo/Redo) tin cậy:** Khắc phục triệt để lỗi mất liên kết giữa đoạn thẳng và điểm sau khi hoàn tác nhiều bước.
- **Bảo mật khóa API:** Bảo vệ an toàn khóa API cho tính năng trợ lý giải toán AI bằng hệ thống mã hóa tích hợp của Windows (DPAPI).
- **Tối ưu hiệu năng và độ ổn định:** Sửa các lỗi nhỏ phát sinh và tối ưu hóa bộ nhớ, giúp ứng dụng khởi động nhanh và hoạt động êm ái hơn.

## English (EN)
**What's new in version 3.1.0**
- **Enhanced Geometric Precision:** Refined triangle classification and geometric property detection for consistent results regardless of vertex order.
- **Smoother Canvas Interactions:** Improved dragging behavior for points, midpoints, and dependent constructions with seamless real-time recalculation.
- **Reliable Undo & Redo:** Resolved link-preservation issues between points and segments across complex undo/redo sequences.
- **Secure Key Storage:** Protected local AI assistant API keys using native Windows DPAPI encryption.
- **Performance & Stability Fixes:** Under-the-hood performance polish and bug fixes for a smoother, more dependable experience.
