# GeoSolver 3D - Phần mềm Trực quan hóa & Giải toán Hình học Không gian Sư phạm

Phân hệ giải toán và trực quan hóa Hình học không gian THPT (Lớp 11, 12) và Đại học Sư phạm.

## Tính năng Trọng tâm
1. Dựng hình khối không gian: Chóp, Lăng trụ, Hộp, Cầu, Trụ, Nón.
2. Vẽ thiết diện tự động với phân biệt nét liền / nét đứt khuất.
3. Tính toán góc, khoảng cách và tọa độ hóa Oxyz.
4. Xoay hình 3D tương tác tự do (3D Orbit Rotation) trên Canvas.
